# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in Tolly Labs contracts, please report it privately using GitHub's **Private Vulnerability Reporting** feature for this repository.

Do not open a public GitHub issue or disclose the vulnerability publicly before we have had an opportunity to review it.

Please include, where applicable:

- affected contract(s) and function(s)
- required preconditions
- exact reproduction steps
- transaction sequence from an unprivileged account
- assets or funds potentially at risk
- expected and actual behavior
- runnable proof of concept
- fork block number and relevant chain configuration

## Testing

Do not exploit or test vulnerabilities against mainnet, interact with real user funds, disrupt production systems, or access data belonging to other users.

Testing should be performed using local environments, testnets, or mainnet forks where appropriate.

## Triage

Reports are evaluated based on their technical details, reproducibility, exploitability, and demonstrated impact.

Severity is determined by Tolly Labs after the issue has been reviewed and independently reproduced.

## Rewards

Tolly Labs does not currently operate a public bug bounty program and does not publish predetermined reward tiers.

Any potential reward is discretionary and may be discussed only after a report has been validated and its severity assessed.

## Disclosure

We ask reporters to keep vulnerability details private while investigation and remediation are ongoing.

If a report is confirmed, we will coordinate an appropriate remediation and disclosure process with the reporter.
